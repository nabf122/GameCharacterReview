# GameCharacterReview

`소녀전선2: 망명` 인형 데이터를 관리하기 위한 React(Vite) 프로젝트입니다.

## 주요 기능

- 인형 정보 입력/수정/삭제
  - 인형명
  - 성급
  - 소속
  - 포지션
  - 속성
  - 추천 장착 무기
  - 추천 장비
  - 이미지 URL
  - 메모
- 화면 분리
  - **관리 화면**: 인형 등록/수정/삭제
  - **조회 화면**: 검색 + 성급 필터 기반 조회
- 총 인형 수 / 5성 인형 수 요약

## 시작하기

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```
