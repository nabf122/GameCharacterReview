# GameCharacterReview

`승리의 여신: 니케` 스쿼드 구성을 연습하기 위한 React(Vite) 프로젝트입니다.

## 주요 기능

- 니케 풀 관리
  - 니케명, 등급, 기업, 병과, 버스트, 코드, 무기, 이미지 URL, 스쿼드 역할 메모 입력
  - 1스킬, 2스킬, 버스트 스킬 정보 입력
  - 등록된 니케 정보 수정/삭제
  - 등록된 니케 검색
- 스쿼드 구성
  - 보유 니케 중 최대 5명을 선택해 현재 스쿼드 구성
  - 니케 이미지를 스쿼드 슬롯으로 드래그앤드롭해 편성
  - 선택된 니케를 슬롯별로 확인하고 개별 제거 또는 전체 비우기
- 스킬 툴팁
  - 니케 이미지에 마우스를 올리면 1스킬, 2스킬, 버스트 스킬 정보 표시
- 구성 분석
  - 버스트 I/II/III 분포 표시
  - 화력형/방어형/지원형 병과 분포 표시
  - 5인 편성, 버스트 순환, 기본 역할 밸런스 체크
- 후보 검색/필터
  - 이름, 기업, 병과, 코드, 무기, 스킬 검색
  - 버스트 단계별 필터링


## 오류 해결 팁

`src/App.jsx`에서 `Unexpected token` 오류가 발생하면 로컬 파일이 이전 버전이거나 일부 줄이 누락된 상태일 수 있습니다. 최신 코드를 받은 뒤 의존성을 다시 설치하고 개발 서버를 재시작하세요.

```bash
git pull
npm install
npm run dev
```
